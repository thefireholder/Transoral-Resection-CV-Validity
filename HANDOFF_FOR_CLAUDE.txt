HOW TO RUN
----------
  cd $TORS_SHARED/result
  export TORS_SHARED=...            # parent of result/ and processed_data/
  bash scripts/rerun/run_local.sh --dry           # prints the plan, checks torch/cuda
  CONDA_ENV=<env> bash scripts/rerun/run_local.sh # ~8-12 h total on a 6 GB laptop GPU; leave it running
  CONDA_ENV=<env> bash scripts/rerun/run_local.sh --only monai   # <- what is needed NOW (sam3/maskrcnn/yolo are done;
                                                  #    their .done markers may be missing here -- --only monai is safe regardless)
  MONAI needs:  pip install "monai==1.5.1" scikit-learn tqdm tensorboard   (monai 1.6 forces torch>=2.8: do NOT let pip
  upgrade torch -- if it tries, install with the version pin above; check `python -c "import torch,torchvision"` after)
  CONDA_ENV=<env> bash scripts/rerun/run_local.sh --sweep   # only if the user wants Figure 5 now (1-2 days)
Order is fixed: sam3 -> maskrcnn -> yolo -> monai (-> sweep). GPU steps are serial (VRAM); post-processing runs in background.
Resumable: finished steps leave scripts/rerun/logs/local/<step>.done and are skipped. Delete a .done to redo a step.
Logs: scripts/rerun/logs/local/<step>.out|.err ; progress: scripts/rerun/logs/local/run_local.log

6 GB VRAM DEFAULTS (already set in run_local.sh; override via env vars)
-----------------------------------------------------------------------
  MRCNN_BATCH=2 MRCNN_LR=0.0025   (cluster recipe is 4 / 0.005; linear LR scaling; record which one was used)
  SAM3_ARGS=--fp16                (fp32 SAM3 weights ~3.5 GB; fp16 is safer)
  YOLO_BATCH=16 YOLO_EPOCHS=60    (yolo11n @640 fits)
  MONAI_BATCH=4 MONAI_EPOCHS=100  (UNet @512 fits at 4; early stopping usually ends it around epoch 40-60; ~2 min/epoch)
  PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
If Mask R-CNN still OOMs at batch 2: MRCNN_BATCH=1 MRCNN_LR=0.00125.  If SAM3 OOMs in fp16, nothing else to cut -- report it.
The recipe actually used is written to scripts/rerun/output/maskrcnn/recipe.txt -- keep it.
